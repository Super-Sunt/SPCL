# SPCL 联机功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 SPCL 顶部放显「联机」标签页，用自建 EasyTier 中继实现跨局域网联机，联机模块随发布包内置。

**Architecture:** 复用 PCL 2.14 自带的 `PageLinkMain`（UI、进程管理、端口转发、邀请码全部保留），把配置来源从官方服务器 `ServerConfig("Link")` 换成新模块 `ModLinkConfig`；中继地址来自新设置 `LinkRelayServer`（发布包不内置）；EasyTier v2.6.4 裁剪版随发布包分发。

**Tech Stack:** VB.NET / WPF / .NET Framework 4.8、EasyTier v2.6.4（`easytier-core` 命令行）、PowerShell 打包脚本。

**依据 spec:** `docs/superpowers/specs/2026-10-24-spcl-link-design.md`

**验证方式:** 本工程无单元测试框架。每个任务用「构建 + 静态检查 + 运行冒烟」验证，Task 10 做本地端到端联机验收（本机同时跑中继与客户端）。

```powershell
param(
    [string]$Proxy = "http://127.0.0.1:7897",
    [string]$Version = "v2.6.4"
)
$ErrorActionPreference = "Stop"
$root = Split-Path $PSScriptRoot -Parent
$out = Join-Path $PSScriptRoot "link-module"
$zip = Join-Path $env:TEMP "easytier-$Version-win64.zip"
New-Item -ItemType Directory -Force $out | Out-Null

$urls = @(
    "https://ghfast.top/https://github.com/EasyTier/EasyTier/releases/download/$Version/easytier-windows-x86_64-$Version.zip",
    "https://github.com/EasyTier/EasyTier/releases/download/$Version/easytier-windows-x86_64-$Version.zip"
)
if (-not (Test-Path $zip) -or (Get-Item $zip).Length -lt 20MB) {
    foreach ($u in $urls) {
        Write-Host "下载 $u"
        curl.exe -x $Proxy -L -sS --max-time 900 -o $zip $u
        if ((Test-Path $zip) -and (Get-Item $zip).Length -gt 20MB) { break }
    }
}
if (-not (Test-Path $zip) -or (Get-Item $zip).Length -lt 20MB) { throw "下载 EasyTier 失败" }

Add-Type -AssemblyName System.IO.Compression.FileSystem
$tmp = Join-Path $env:TEMP "easytier-extract"
Remove-Item $tmp -Recurse -Force -ErrorAction SilentlyContinue
[IO.Compression.ZipFile]::ExtractToDirectory($zip, $tmp)
$src = Get-ChildItem $tmp -Directory | Select-Object -First 1
foreach ($f in @("easytier-core.exe", "easytier-cli.exe", "Packet.dll", "wintun.dll", "WinDivert64.sys")) {
    Copy-Item (Join-Path $src.FullName $f) $out -Force
}
# 重命名为启动器期望的名字
Move-Item (Join-Path $out "easytier-core.exe") (Join-Path $out "联机模块.exe") -Force
Move-Item (Join-Path $out "easytier-cli.exe") (Join-Path $out "联机模块 CLI.exe") -Force
# 许可证
curl.exe -x $Proxy -L -sS --max-time 120 -o (Join-Path $out "LICENSE.txt") "https://raw.githubusercontent.com/EasyTier/EasyTier/$Version/LICENSE"

Get-ChildItem $out | Select-Object Name, @{n='MB'; e={[math]::Round($_.Length/1MB,2)}} | Format-Table -AutoSize
Write-Host "模块准备完成：$out"
```

**Files:**

```vb
''' <summary>
''' 联机功能的本地配置，替代官方服务器下发的 ServerConfig("Link")。
''' </summary>
Friend Module ModLinkConfig

    ''' <summary>
    ''' 内置联机模块（EasyTier）版本号。更换内置模块时必须 +1，启动器据此判断是否需要重新安装。
    ''' </summary>
    Public Const EasyTierVersion As Integer = 3

    ''' <summary>
    ''' EasyTier 基础启动参数（原由官方服务器下发）。其余参数由联机页按角色拼接。
    ''' </summary>
    Public Const BaseArguments As String = ""

    ''' <summary>
    ''' 内置模块缺失时的回退下载地址，{arch} 会替换为 x86_64 / i686 / arm64。
    ''' </summary>
    Public ReadOnly FallbackDownloads As String() = {
        "https://ghfast.top/https://github.com/EasyTier/EasyTier/releases/download/v2.6.4/easytier-windows-{arch}-v2.6.4.zip",
        "https://github.com/EasyTier/EasyTier/releases/download/v2.6.4/easytier-windows-{arch}-v2.6.4.zip"
    }

    ''' <summary>
    ''' 当前应连接的节点列表：自定义节点优先，其次是中继服务器设置。
    ''' </summary>
    Public Function GetRelayPeers() As String
        Dim Custom As String = Settings.Get(Of String)("LinkCustomPeer")
        If Not String.IsNullOrWhiteSpace(Custom) Then Return Custom
        Return Settings.Get(Of String)("LinkRelayServer")
    End Function

    ''' <summary>
    ''' 发布包内置的联机模块文件夹（与 exe 同级）。缺少必需文件时返回 Nothing。
    ''' </summary>
    Public ReadOnly Property BundledModuleFolder As String
        Get
            Dim Folder As String = Paths.Base & "联机模块\"
            If FileUtils.Exists(Folder & "联机模块.exe") AndAlso
               FileUtils.Exists(Folder & "联机模块 CLI.exe") AndAlso
               FileUtils.Exists(Folder & "Packet.dll") Then Return Folder
            Return Nothing
        End Get
    End Property

End Module
```

```powershell
param(

)
$ErrorActionPreference = "Stop"
$root = Split-Path $PSScriptRoot -Parent
Set-Location $root

& "$PSScriptRoot\build-spcl.ps1"
if ($LASTEXITCODE -ne 0) { throw "构建失败" }

$stage = Join-Path $root "dist\SPCL"
Remove-Item $stage -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force $stage | Out-Null

Copy-Item "Plain Craft Launcher 2\bin\SPCL.exe" $stage -Force
Copy-Item "LICENCE" $stage -Force
Copy-Item "README-SPCL.txt" (Join-Path $stage "README.txt") -Force
icacls (Join-Path $stage "SPCL.exe") /setintegritylevel Medium | Out-Null

$moduleSrc = Join-Path $PSScriptRoot "link-module"
if (-not (Test-Path (Join-Path $moduleSrc "联机模块.exe"))) {
    throw "缺少联机模块，请先运行 tools\prepare-link-module.ps1"
}
$moduleDst = Join-Path $stage "联机模块"
New-Item -ItemType Directory -Force $moduleDst | Out-Null
Copy-Item (Join-Path $moduleSrc "*") $moduleDst -Force

$zip = Join-Path $root "dist\SPCL-$Version-win64.zip"
Remove-Item $zip -Force -ErrorAction SilentlyContinue
Compress-Archive -Path (Join-Path $stage "*") -DestinationPath $zip -Force
Get-Item $zip | Select-Object FullName, Length
```
